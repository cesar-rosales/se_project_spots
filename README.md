# Spots

**Spots** is a responsive, social media–style web application that allows users to manage a profile and create image-based posts through an interactive, modal-driven interface.

This project demonstrates my ability to structure front-end code using modular JavaScript, handle UI state, implement form validation, and translate a Figma design into a fully responsive web application.

## ✨ Features

- Edit user profile information
- Add new image cards with title and image URL
- Like and unlike cards
- Delete cards
- Image preview modal with caption
- Modal close via button, overlay click, and ESC key
- Client-side form validation with real-time feedback
- Empty state messaging when no posts exist
- Fully responsive, mobile-first layout

---

## 🛠 Tech Stack

- **HTML5** – semantic markup and accessibility best practices  
- **CSS3** – BEM methodology, responsive layouts, media queries  
- **JavaScript (ES6+)** – modular architecture, DOM manipulation, event handling  
- **Webpack** – bundling, asset management, and build optimization  
- **GitHub Pages** – deployment
